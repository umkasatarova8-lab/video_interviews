# Interview — WebRTC видеособеседование

## Запуск
1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Установите расширение Live Server (если не установлено).
4. Правой кнопкой по `index.html` → **Open with Live Server**.
5. Разрешите браузеру доступ к камере и микрофону.
6. Откройте сайт в двух окнах/вкладках и нажмите «Подключиться» в каждом.

Можно также запускать локальный сайт через HTTPS или localhost — доступ к камере браузер разрешает на localhost.

## Примечание
Сервер signaling передаёт сообщения между участниками. Протокол обработан с типами `offer`, `answer`, `ice-candidate` и `peer-left`. Если сервер использует другое имя поля для ICE-кандидата или дополнительные форматы, потребуется небольшая корректировка.
